# チルドリル

Lo-Fiの音楽を流しながら、マスコットの「チルネコ」と並んで静かに続ける算数ドリルです。ブラウザだけで動きます。

遊ぶ：<https://chill-drill.tanosix.com/>

問題は画面を切り替えずにノートへ流れてきて、チルネコが鉛筆で数字を書き、まちがえると消しゴムで消します。区切りは問題数ではなく曲の長さです。解くほど部屋の時間が静かに進み、鉢植えが育ち、窓の外の景色が移ろいます。急がせる仕組みはありません。

姉妹作の [ドパドリル](https://github.com/grmchn/dopa-drill)（解くほど演出が盛り上がる計算ドリル）から、出題・保存・継続の仕組みを移植しています。

## 特徴

- 小学1〜6年の計算58スキル（学習指導要領に基づく）。筆算の途中入力、小数、分数、割合など
- 「じぶんレベル」モード、学年別モード、ふくしゅう、スキルツリー
- 長さは1〜10分（既定3分）。完走で100点。正答率が約85%に留まるよう難しさを調整します
- 初回正解率が80%以上なら「おかわり」でカセットを1本ずつ延ばせます（最大5本）
- 「マイペース」（回答間隔のそろい具合）と「チル」（落ち着いて解くほど貯まる値）。チルが貯まるとコレクションが順に届きます
- きょうのクエスト、カレンダー、トロフィー、日替わりの天気、きょうの でき（気分のはんこ）、深呼吸のイントロ、タイムラプス
- 音楽・環境音・効果音はすべてWeb Audio APIでリアルタイムに合成しています（録音素材は使っていません）。曲はこのゲームのために作ったオリジナルで、データ（`app/audio/songs/`）として収録しています
- スマートフォンの縦画面とPCに対応。PCでは数字キーとBackspaceで入力できます
- 記録はすべて端末内（localStorage）に保存し、外部には送信しません

## 遊び方（ローカル）

ビルドは不要です。`app/` を静的に配信するだけで動きます。

```bash
python3 -m http.server 8000 -d app
```

ブラウザで `http://localhost:8000/` を開いてください。ES Modulesを使っているため、`file://` で直接開くと動きません。

## テスト

Node.js 20以上で実行します。

```bash
node --test tests/*.test.mjs
```

## 作曲ツール

曲データの編集・試聴用のツールです。リポジトリのルートを静的に配信して開きます。

```bash
python3 -m http.server 8000
```

`http://localhost:8000/tools/lofi-studio/index.html` を開いてください。ゲームと同じ音源エンジンで鳴ります。

## 構成

| パス | 内容 |
| --- | --- |
| `app/` | ゲーム本体（依存ライブラリなしのES Modules） |
| `app/audio/songs/` | 曲データ（JSON） |
| `docs/SPEC.md` | 仕様書 |
| `docs/audio_engine.md` | 音源エンジンと曲データの形式 |
| `docs/difficulty.md` | 難しさの調整 |
| `docs/collection.md`、`docs/trophies.md` | コレクション・トロフィーの一覧 |
| `docs/chill-neko.svg` | チルネコの造形の原典 |
| `tests/` | 単体テスト |
| `tools/lofi-studio/` | 作曲・音作りツール |
| `tools/` | 曲データの生成、ドキュメントの生成、難しさのシミュレーション、配信用ファイルの作成 |
