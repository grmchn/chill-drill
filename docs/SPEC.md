# チルドリル — 仕様書（実装版）

チルドリルは、Lo-Fiの音楽を流しながら、マスコットのチルネコと並んで静かに続ける算数ドリルです。姉妹作ドパドリル（解くほど演出が増える「短距離走」）に対し、解くほど部屋の時間が静かに進む「マラソン」を体験の軸にしています。本書は現在の実装の動作を説明します。数値は今後の調整で変わることがあります。

## 1. 画面と流れ

| 画面 | 内容 |
| --- | --- |
| タイトル（部屋） | 夜の部屋の机。ノートの表紙にロゴ、じぶんレベル、ふくしゅう、1〜6ねん、スキルツリー・トロフィー・コレクション（ながさは設定へ移した）。下にきょうのクエストとカレンダー（きょうの てんき を表示）。部屋の鉢植え・棚・ラジカセ・机の左手前のシールカード・まくらからも開ける。PCでは表紙とカード以外の空き部分のクリックが部屋に届く |
| プレイ | 上に部屋、中央にノート、下に木のテンキー。上部にカセットテープ（リールの巻き具合とラベルの帯で進み具合）、時計（設定時）、音、「ここまで」。おかわり中はカセットの棚（色違いのカセット、終わったカセットの問題数、最大5本の点線枠） |
| 結果 | ノートの次のページ（基本のあとも、おかわりのあとも同じ1枚）：得点（おかわりのあとは内訳とカセットごとの問題数）、といた問題、初回正解、時間、おしい、ペース、タイムラプス（部屋の早回しと、解いた問題が順に書き込まれるノート）、のびたよ、スキルの変化、クエスト、静かなお知らせ、きょうの でき（その日最初のプレイのみ）。「おかわり」（条件を満たしたとき。おかわりのあとは何度でも）または「もう いちど」、「ふくしゅう」、「きょうは ここまで」（タイトルへ）。おかわりのあとは窓の外が明け方になり、チルネコが伸びをする。プレイ中に「ここまで」でやめたときは「とちゅうまでの ページ」（得点なし、記録しないことを添える）を出し、「へやに もどる」でタイトルへ |

流れ：タイトル → 基本（曲が終わるまで） → 結果 → タイトル。おかわりは結果から何度でも：結果 → おかわり → 結果（終わりの画面は廃止し、結果画面を1つにした）。

初回起動時は、チルネコが画面の各所へ移動して前足で指しながら、遊びかた（ようこそ・じぶんレベル・学年・はじめる）を案内する（`app/js/coach.js`）。ほかの説明（スキルツリー、トロフィー、コレクション、クエスト、カレンダー、シール、まくら、とくとき、おかわり、きょり、せってい）は「？」からいつでも見られる。

## 2. 基本（時間制）

- 長さは設定のスライダーで1〜10分（既定3分）。1曲を選んだ長さに合わせて鳴らす（曲の段落を繰り返して合わせるため、実際はおよそ±0.3分）。おかわりのカセット1本も同じ長さ。
- 最初の2小節（約6秒）は深呼吸のイントロ。「まずは いっしょに／しんこきゅう」の案内と「すって…」「はいて…」に合わせて、ノートの光の玉・画面の電球色の光・デスクライトが1回の呼吸でふくらみ、しぼむ。玉の中に問題開始までの秒数を数える。チルネコが伸びをする。数字キーを押すとすぐ始まる。設定で無効にできる。
- 問題は画面を切り替えずにノートへ流れてくる。解き終えた問題は少し上へ浮きながら完全に消える。
- 正解1問ごとに机の鉢植えの葉が1枚増える。1鉢は葉9枚までで、10問目で花が咲き、チルネコが新しい鉢を運んできて隣に置く。11問目からは新しい鉢が伸びる。机には2鉢まで並び、古い花の鉢は窓辺へ移る。
- 曲が終わった時点で解いている問題は最後まで解ける（音楽はアウトロをループして待つ）。解き終えたところで締めの和音が鳴り、基本が終わる。問題の間で曲が終わった場合はそのまま終わる。
- 進み具合は、カセットのリールの巻き具合と、カセット下部のラベルの帯（曲の長さに対して満ちていく）で示す。設定で時計（「経過 / 全体の長さ」）を表示できる。
- 完走で100点。初回正解率（途中入力を含めて誤答なしで完了した問題の割合）が80%以上なら、おかわりを解放する。
- 「ここまで」で途中終了できる。基本の途中で終えると履歴は残らないが、解いた問題の習熟は残る。
- タブを隠す・休憩中は、時計と音楽が止まる。
- ふくしゅうは、まちがえた問題（最大10問）を解き終えたら終わる。

## 3. ちょうどいい難しさ

直近8問の初回正解率が約85%になるよう、1問ごとに難しさを少し上げ下げします。じぶんレベルは練習中・NEWのスキルとマスター済みのスキルの割合で、学年べつはその学年のスキルの段で調整します。学年べつでは、おかわり・むかしのノートも含めて選んだ学年のスキルだけを出します。初回のじぶんレベルは実力チェック（前提をとばしながら進む）です。詳細は `docs/difficulty.md`。

## 4. 入力

- 専用テンキー（7-8-9 / 4-5-6 / 1-2-3 / ⌫-0）。PCでは数字キー、Backspace。Escapeで「ここまで」の確認。
- 1マスずつ判定し、正しければチルネコが鉛筆で数字を書く（手書き風の数字が筆順どおりに0.2秒ほどで現れる）。連打すると前の数字をすぐ書き終えて次へ進む。判定は押した瞬間で、演出が入力を待たせない。
- 誤答の数字は書いたあと、チルネコが鉛筆を持ち替えて消しゴムでこすって消す。うっすら跡が残る。赤い×やブザーはない。
- 同じマスで2回まちがえると見るべき数字がうっすら光り、3回で考え方のヒント（答えは出さない）。
- 筆算の1行が終わると小さなチェック、問題が終わると赤鉛筆の丸と肉球のはんこ。
- 正解の音は和音の構成音で鳴る短い型で、解いた数に応じて型が増える（0問〜上行3音、5問〜下行・2音、12問〜4音上行・きらめき、20問〜ターン・装飾音・分散和音。同じ型は続けない）。

## 5. マイペースとチル

- マイペース：直近5マスの回答間隔のばらつき（変動係数0.35以下）で「いいペース」を判定する。数値は出さず、いいペースが続くと音楽のこもりがほどけ、デスクライトが少し明るくなる。崩れても数秒かけて戻るだけ。
- チル（きょりを置き換え）：正しく書いた数字1つで1チル。そのときのペースが落ち着いている（フロー0.6以上）と2チル。おまけ：初回正解の問題 +2、いいペースで解いた問題が5問つづくごと +5、その日はじめてのプレイ +10、ひとやすみ +5。減らない。日をまたいで累計し、結果画面（今回の内訳・累計・次に届くコレクション）、プレイ中の上部（今回の値）、カレンダーの下（累計）に出す。
- コレクション：44のアイテムが決まった順に、累計チルのしきい値（n番目は 40(n+1)＋15n(n+1)/2、最初は40、最後は15,950）で届く。使って減らない。トロフィーはごほうびなしの達成記録。

## 6. おかわり

- 解放：基本の初回正解率80%以上。加点：k問目（0から）に10＋5k点。
- 1周＝基本と同じ長さのカセット1本。基本が1本め、おかわりは2〜5本め（最大5本）。
- おかわりのカセットが終わった時点で、そのカセットの初回正解率が80%以上なら次のカセットへ自動で続く。下回ると終わる。時間切れのとき解いている問題は最後まで解ける。
- 難しさは3問ごとに上がる。音楽は同じ曲のB面（変奏）に切り替わり、終わりまで続く。「ここまで」でいつでも得点を確定できる。
- 表示：上部にカセットの棚（PCは横並び、スマートフォンはバーの下の段）。終わったカセットの下に解いた問題数、回っているカセットは進み具合のみ、未使用は点線枠。終わりの画面にカセットごとの内訳。
- はじめてのおかわりでは、時間を止めてチルネコが説明する（3枚、`TOURS.okawari`）。端末に `okawariGuideSeen` を記録し、2回め以降は出さない。オートプレイでは出さない。

## 7. 休憩

続けて遊んだ時間が目安（初期25分、設定でなし・15・25・40分）に達すると、問題の区切りでチルネコが伸びをして休憩を勧める。休む場合は時計と音楽を止め、呼吸の円を表示する。

## 8. 続ける仕組み

ドパドリル公開版と同じ規則で、名称・見た目・コンボ等に依存する条件を置き換えています（[grmchn/dopa-drill](https://github.com/grmchn/dopa-drill)）。

- 履歴とカレンダー：日ごとの肉球、シール、きょうの でき、おやすみの日。日付から詳細と、きょうの できの変更。
- ログインシール：机の上のシールカードをタップで受け取る（開いた瞬間のダイアログはない）。月・雨粒・葉・湯のみ・本・星・満月の7日周期。
- おやすみまくら：遊ばなかった日をおやすみの日にして連続をつなぐ（最大3こ、7日以内）。部屋にまくらが置かれていたら提案。
- デイリークエスト：簡単2＋手間1、約15分。いいペース・チル・おかわり等。3つ達成でまくら1こ。
- トロフィー：12分類326種（`docs/trophies.md`）。一覧はシリーズごとに1行（獲得済みの最上位、次の目標、進み具合）で、開くと全段階。絞り込みは ぜんぶ・ゲットした・まだ・もうすぐ（次の目標に近い順）。
- スキルツリー：58スキル。ドパドリルと同じく上から下へ並ぶタイル表示（夜の紺地に紙色のタイル、ティールと電球色）。長押し・Deleteで記録を消せる。
- 星（☆1〜5）、ほこり（さびつき）、前回とくらべる（正確さを先に表示）、むかしのノート（タイムカプセル）。
- コレクション：8カテゴリ46種（`docs/collection.md`）。固定またはおまかせ。

通知はプレイ中に割り込まない。プレイ中はノートの余白に小さなシールが貼られ、小さなベルが鳴るだけで、内容は結果・終わりの画面に静かに並ぶ。

## 9. 音

Lo-Fi の6曲（各4分前後、70〜84 BPM）と各B面。すべて合成で、録音素材はない（`docs/audio_engine.md`）。入力音は現在のコードの構成音から選ばれ、解くと旋律のように聞こえる。環境音（雨・焚き火・虫の声）は音楽とは別に音量を調整できる。雨は音程のないごく短い粒の集まり、焚き火ははぜる音が主役で炎の地のノイズはごく小さい。カフェは合成で自然にならず削除した（保存済みの「カフェ」は「てんきに あわせる」として扱う）。既定の「てんきに あわせる」は、こさめの日は雨、7〜10月のはれ・くもりの日は虫の声、それ以外は無音にする。

### 9.1 日替わりの天気

天気は日付から決まり、同じ日は何度開いても同じになる（`app/js/weather.js`）。種類は はれ・くもり・こさめ・ゆき の4つで、月ごとの重みで選ぶ（ゆきは12〜3月だけ、6月はこさめが多い）。窓の景色が天気を変えることがある：ゆきげしきでは雨が雪になり、さくらなみきでは、はれ・くもりの日に花びらが舞う。くもりは雲と星の減光、こさめは雲・空の減光・月がかすむ・雨粒、ゆきは雪が降る。カレンダーに「きょうの てんき」を表示する。

## 10. 設定とアクセシビリティ

| 設定 | 初期値 |
| --- | --- |
| ながさ | 3ぷん |
| おと | オン |
| ぜんたい・おんがく・こうかおん | 80% |
| かんきょうおん | てんきに あわせる・50% |
| とけい | なし |
| しんこきゅうから はじめる | オン |
| ひとやすみの めやす | 25ふん |
| うごきの つよさ | 端末の「動きを減らす」がオンなら0%、それ以外100% |
| じどうで プレイを みる | オートプレイ（下記） |
| すべて リセット | 2回の確認で端末内のデータを消す |

各項目の名前の横の「？」をタップすると説明が開く。PCでは名前にマウスを乗せても説明が出る。

オートプレイ：全学年から易しい順（3問ごとに1学年上）に1きょくぶんを、通常の入力・判定・演出で自動で解く（ときどき誤答も入れる）。結果 → おかわり（条件を満たせば4問） → 終わり → タイトルへ自動で戻る。タップ・キーで終了（開始後600msは無視）。履歴・習熟・統計・クエスト・トロフィーに記録しない。

動きの強さ0%では、雨・湯気・カーテン・呼吸・書く・消す・鉢を運ぶアニメーションを止め、最終状態を表示します。描画は30fps（0%では4fps）に抑えています。ボタンのアクセシブル名、フォーカス表示、ダイアログ内のフォーカス循環、Escapeで閉じる操作を用意しています。

## 11. 保存とプライバシー

データはブラウザの localStorage（キー `chill-drill:v1`）だけに保存し、サーバーへ送信しません。保存するもの：設定、履歴（最大3000件）、習熟と星、統計、トロフィー、コレクションの選択、シール、まくら、クエスト、きょうの でき、初回ガイドの表示済み。

## 12. 技術構成

ビルド不要の静的 HTML/CSS/JavaScript（ES Modules）。出題・保存・継続の仕組みはドパドリルから移植（[grmchn/dopa-drill](https://github.com/grmchn/dopa-drill)）。部屋はSVGと窓の中のCanvas、チルネコは部位を動かすSVG、音はWeb Audio API。起動・テスト・確認用URLは `docs/dev.md`。作曲・音作りは `tools/lofi-studio/`。
